# Задача

Реализовать сервис котировок валютных курсов. Сервис предоставляет асинхронный
интерфейс, т.е. пользователь сначала выполняет запрос на обновление котировки, а
затем, через некоторое время, запрос на получение котировки. При этом
непосредственно обновление котировки происходит в фоновом режиме.

# Требования

Сервис нужно написать на языке Go. Для взаимодействия сервис должен
предоставлять API по протоколу HTTP в формате JSON. API должен предоставлять
следующие возможности:

1. Обновить котировку. В запросе указывается код валюты (напр. EUR/MXN). Сервис
   присваивает запросу обновления идентификатор. В ответе сервис отдает
   идентификатор обновления. Сервис выполняет обновление котировки в фоновом
   режиме, т.е. обработчик запроса не должен выполнять обновление.
2. Получить котировку по идентификатору. В запросе указывается идентификатор
   обновления (п.1), в ответе сервис отдает значение цены и время обновления.
3. Получить последнее значение котировки. В запросе указывается код валюты. В
   ответе сервис отдает значение цены и время обновления.

В качестве базы данных предлагается использовать PostgreSQL, допускается другая
БД по выбору разработчика. Обновление котировки в фоновом режиме можно
реализовать любым способом на выбор разработчика: периодические проверки (cron),
по триггеру (напр. через каналы) и т.п. За значениями цены сервис ходит во
внешний источник данных. Источником данных для котировок может служить любой
внешний API. Например `https://exchangeratesapi.io/`. Достаточно реализовать
ограниченное число котировок (например, валюты USD, EUR, MXN); добавлять
поддержку всех возможных валют не требуется.

# Дополнительно

В качестве дополнительных (но не обязательных) условий можно рассмотреть
следующие:

- Unit-тесты
- Контейнеризация (Docker)
- Идемпотентность обновления котировки
- Swagger (OpenAPI) файл со спецификацией API.
